# Shared repository plan

Updated 2026-11-12.

The setup branch adds reproducible development to the existing GitHub history.
Use [the collaborator guide](docs/GETTING_STARTED.md) and personal feature
branches for ongoing work. Original model sources and proposal documents remain
unchanged; benchmark and research infrastructure was imported from the maintained
local project.

Before a new experiment, obtain the exact dataset/provenance bundle, review an
inherited config, validate the GPU runtime, choose a new output directory and
record the source commit. Preserve historical freezes and scored runs.

Earlier research plans are archived in
[local-handoff-20261112](docs/archive/local-handoff-20261112/README.md).
