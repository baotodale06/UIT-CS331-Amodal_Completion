Inspect each case

  1. Identify the intended target in the full original.
  2. Compare visible target and returned completion. Use native images for small details.
  3. Check the full original against raw RGB for secondary objects.
  4. Rate all six criteria, mark confounds and write a brief evidence note.

Overview columns 1–4 share crop and scale. Native image canvases may differ due to cropping/outpainting. Transparent regions are outside masks. The reduced JPEG overview cannot resolve every texture detail.

Use the scale consistently

0 assessable, no clear defect · 1 mild/local · 2 clear/consequential · 3 extensive/severe · U uncertain/unassessable · NA no applicable pattern (pattern only).

Unknown is not a pass. Blue = retained visible support; orange = added predicted support; pink = lost support. Orange is not true hidden ground truth. Judge consistency, not unknowable hidden-pixel accuracy.

A missing limb alone is not semantic drift. A second object already in the source is not an added object. Record segmentation/geometry problems separately.

Work alone without AI, model scores, earlier annotations or the project report. Break after each 20-case batch. Download a JSON backup after each batch and before closing. Browser storage may not survive moving folders or clearing data. The form works offline and sends nothing.
